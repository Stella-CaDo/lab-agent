## 第 0 章 动手前，先把这几件事搞明白

### 0.1 最后做出来是个什么东西

一个"实验室预约系统"网站，打开浏览器就能用，**不需要装数据库、不需要启动后端**。左边一排菜单，点进去是不同页面：

| 菜单       | 能干什么                                                                |
| ---------- | ----------------------------------------------------------------------- |
| 系统首页   | 4 个数字卡片（实验室数、今日预约、待审核、占用率）+ 2 张图 + 待审核列表 |
| 实验室管理 | 搜索、翻页、新增、编辑、删除实验室                                      |
| 设备管理   | 按实验室筛选设备，搜设备名                                              |
| 预约管理   | 提交预约（会检查时间冲突）、通过/驳回/取消                              |
| 数据统计   | 4 张图：趋势、状态占比、使用次数、热力图                                |
| 用户管理   | 只读的用户列表                                                          |
| 登录页     | 输账号密码才能进上面这些页面                                            |

**为什么不用后端也能用？** 因为数据存在**浏览器自己身上**（`localStorage`），接口由前端代码"假装"实现（叫 mock）。你刷新网页数据还在，换台电脑数据就没了——这对课程作业刚刚好。

### 0.8 网络请求：我们没有后端，答辩怎么说

**大白话**：正常情况下，页面用 axios 把请求发给服务器，服务器查数据库再返回。我们没有服务器，所以：

- axios 还是照常发请求；
- 但在"最后一步"装了一个**适配器（adapter）**，把请求转交给浏览器里的 mock；
- mock 从 `localStorage` 里读写数据，再把结果原样返回。

**结果**：代码写法和有后端时**一模一样**，但 F12 的 Network 面板里看不到请求——这是正常的，不是 bug。

**答辩时照这三句说**：

1. 网络层用 axios 统一封装：baseURL、超时、token、业务码判断、错误提示都在拦截器里，接口按 REST 风格拆成 7 个模块。
2. 因为没有后端，我用 axios 自定义 adapter 把请求接到浏览器内的 mock，数据持久化到 localStorage，相当于把"服务端"换成了适配器。
3. 所以 Network 面板里没有请求，但 axios 的请求/响应链路、loading、错误处理都是真实生效的。

**万一老师坚持要看 Network 里的请求**：可以换成 MSW（Mock Service Worker），仍然是纯前端 + localStorage，只改 mock 层和 `main.js`，页面和 api 文件不动。现在先不做，避免多一个依赖。

> 可以加但不影响主干的扩展：表格导出 CSV、登录后首页显示"你好，张管理"。主题切换、日历视图太费时间，不建议。

### 1.4 17 个接口是什么

"接口"就是页面和数据的约定：**用哪个地址、带什么参数、返回什么**。我们的接口都长这样：

```json
成功：{ "code": 0, "msg": "ok", "data": 具体数据 }
```

```js
    if (value === undefined || value === null || value === "") continue;
    query[key] = String(value);
  }
  return query;

        r.labId === lab.id &&
        r.date === body.date &&
        (r.status === "pending" || r.status === "approved") &&
        isOverlap(body.startTime, body.endTime, r.startTime, r.endTime),
    );
    if (conflict)
      return fail(
        "时段冲突：" +
          conflict.startTime +
          "-" +
          conflict.endTime +
          " 已被占用",
      );
    const record = {
      id: nextId(db.reservations),
      labId: lab.id,
      userId: Number(body.userId) || 1,
      date: body.date,
      startTime: body.startTime,
      endTime: body.endTime,
      purpose: body.purpose || "课程实验",
      attendees: Number(body.attendees) || 1,
      status: "pending",
      createdAt: offsetDate(0) + " " + new Date().toTimeString().slice(0, 5),
    };
    db.reservations.push(record);
    saveDb();
    return ok(withNames(record), "预约提交成功，等待审核");
  }

  m = /^\/reservations\/(\d+)\/status$/.exec(path);
  if (m && method === "PUT") {
    const target = db.reservations.find((r) => r.id === Number(m[1]));
    if (!target) return fail("预约不存在");
    // 状态机：待审核 → 通过/驳回；已通过 → 取消
    const allowMap = {
      pending: ["approved", "rejected"],
      approved: ["cancelled"],
    };
    if (!(allowMap[target.status] || []).includes(body.status))
      return fail("当前状态不允许这样流转");
    target.status = body.status;
    saveDb();
    return ok(withNames(target), "状态已更新");
  }

  m = /^\/reservations\/(\d+)$/.exec(path);
  if (m && method === "DELETE") {
    const idx = db.reservations.findIndex((r) => r.id === Number(m[1]));
    if (idx === -1) return fail("预约不存在");
    db.reservations.splice(idx, 1);
    saveDb();
    return ok(null, "删除成功");
  }

  /* ===== 设备（B2 调用） ===== */
  if (path === "/devices" && method === "GET") {
    const keyword = (query.keyword || "").trim();
    const labId = query.labId || "";
    const filtered = db.devices
      .filter(
        (d) =>
          (!labId || String(d.labId) === labId) &&
          (!keyword || d.name.includes(keyword) || d.model.includes(keyword)),
      )
      .map((d) => ({
        ...d,
        labName: (db.labs.find((l) => l.id === d.labId) || {}).name || "-",
      }));
    return ok(paginate(filtered, query.page, query.size));
  }

  /* ===== 用户（B3 调用，只读） ===== */
  if (path === "/users" && method === "GET") {
    const list = db.users.map((u) => {
      const item = { ...u };
      delete item.password;
      return item;
    });
    return ok(paginate(list, query.page, query.size));
  }

  /* ===== 统计（A3 / A4 调用） ===== */
  if (path === "/stats/overview" && method === "GET") {
    const today = offsetDate(0);
    const usedToday = new Set(
      db.reservations
        .filter(
          (r) =>
            r.date === today &&
            r.status !== "rejected" &&
            r.status !== "cancelled",
        )
        .map((r) => r.labId + "|" + r.startTime),
    ).size;
    return ok({
      labCount: db.labs.length,
      labAvailable: db.labs.filter((l) => l.status === "available").length,
      todayReservations: db.reservations.filter((r) => r.date === today).length,
      pendingCount: db.reservations.filter((r) => r.status === "pending")
        .length,
      avgUsage:
        Math.round((usedToday / (db.labs.length * TIME_SLOTS.length)) * 1000) /
        10,
    });
  }

  if (path === "/stats/trend" && method === "GET") {
    const range = Number(query.range) || 7;
    const days = [];
    for (let i = range - 1; i >= 0; i--) {
      const date = offsetDate(-i);
      days.push({
        date: date.slice(5),
        count: db.reservations.filter((r) => r.date === date).length,
      });
    }
    return ok(days);
  }

  if (path === "/stats/lab-usage" && method === "GET") {
    const list = db.labs
      .map((l) => ({
        name: l.name,
        count: db.reservations.filter(
          (r) => r.labId === l.id && r.status === "approved",
        ).length,
      }))
      .sort((a, b) => b.count - a.count);
    return ok(list);
  }

  if (path === "/stats/status-ratio" && method === "GET") {
    const nameMap = {
      pending: "待审核",
      approved: "已通过",
      rejected: "已驳回",
      cancelled: "已取消",
    };
    const list = Object.keys(nameMap).map((k) => ({
      name: nameMap[k],
      value: db.reservations.filter((r) => r.status === k).length,
    }));
    return ok(list);
  }

  if (path === "/stats/heatmap" && method === "GET") {
    const data = [];
    for (let day = 0; day < 7; day++) {
      for (let slot = 0; slot < TIME_SLOTS.length; slot++) {
        const value = db.reservations.filter((r) => {
          const d = new Date(r.date + "T00:00:00");
          return (
            d.getDay() === day &&
            r.startTime === TIME_SLOTS[slot] &&
            r.status !== "rejected" &&
            r.status !== "cancelled"
          );
        }).length;
        data.push([day, slot, value]);
      }
    }
    return ok({
      days: ["周日", "周一", "周二", "周三", "周四", "周五", "周六"],
      slots: TIME_SLOTS,
      data,
    });
  }

  return fail("接口不存在: " + method + " " + path);
}
```

### 1.7 第 3 个文件：`src/api/request.js`（请求总开关）

**它干嘛**：创建 axios 实例，统一加 `/api` 前缀、自动带 token、统一弹错误提示，并把请求交给 mock。

**怎么做**：在 `src/api/` 下新建 `request.js`（`api` 文件夹没有就新建），粘贴：

```js
// axios 统一封装：mock adapter + token 注入 + 业务码判断 + 统一错误提示
import axios from "axios";
import { ElMessage } from "element-plus";
// 浏览器内的 mock 接口层：所有 /api/* 都交给它，不发真实网络请求
import { mockAdapter } from "@/mock/index.js";

const request = axios.create({
  baseURL: "/api",
  timeout: 10000,
  adapter: mockAdapter, // 关键：全站请求在浏览器里就地处理
});

// 请求拦截：自动带 token（A1 登录后才有值）
request.interceptors.request.use((config) => {
  const token = localStorage.getItem("lab_token");
  if (token) config.headers.Authorization = "Bearer " + token;
  return config;
});

// 响应拦截：code 为 0 才算成功，直接把 data 返回给业务层
request.interceptors.response.use(
  (response) => {
    const body = response.data;
    if (body && body.code === 0) return body.data;
    const msg = (body && body.msg) || "请求失败";
    ElMessage.error(msg);
    return Promise.reject(new Error(msg));
  },
  (error) => {
    const data = error.response && error.response.data;
    const msg = (data && data.msg) || error.message || "网络异常";
    ElMessage.error(msg);
    return Promise.reject(error);
  },
);

export default request;
```

**代码里在干嘛**：

- `axios.create({...})`：造一个"定制版 axios"
- `adapter: mockAdapter`：**这一行是关键**，让请求不真的发到网上，而是交给 mock
- 请求拦截器：每次请求自动带上登录 token
- 响应拦截器：`code === 0` 就把 `data` 返回；否则弹红字并报错

**怎么确认成功**：保存后终端没有红字。

### 1.9 第 5 个文件：`src/stores/lab.js`（共享数据仓库）

**它干嘛**：实验室的列表、总数、加载状态、查询条件都放这里，实验室页和预约页共用。

```js
import { defineStore } from "pinia";
import { ref } from "vue";
import { getLabList, createLab, updateLab, deleteLab } from "@/api/lab";

export const useLabStore = defineStore("lab", () => {
  const list = ref([]);
  const total = ref(0);
  const loading = ref(false);
  // 查询条件放 store，页面只负责 v-model 绑定
  const query = ref({
    keyword: "",
    building: "",
    status: "",
    page: 1,
    size: 10,
  });

  async function fetchList(extra = {}) {
    loading.value = true;
    try {
      const data = await getLabList({ ...query.value, ...extra });
      list.value = data.list;
      total.value = data.total;
    } finally {
      loading.value = false;
    }
  }

  /** 有 id 走修改，没有走新增；表单里的 id 不发给 mock */
  async function saveLab(form) {
    const { id, ...payload } = form;
    if (id) await updateLab(id, payload);
    else await createLab(payload);
    await fetchList();
  }

  async function removeLab(id) {
    await deleteLab(id);
    await fetchList();
  }

  /** 下拉框用：一次取全部实验室（最多 100 条） */
  async function fetchAllLabs() {
    const data = await getLabList({ page: 1, size: 100 });
    return data.list;
  }

  return {
    list,
    total,
    loading,
    query,
    fetchList,
    saveLab,
    removeLab,
    fetchAllLabs,
  };
});
```

**代码里在干嘛**：

- `list` / `total` / `loading`：列表数据、总条数、是否加载中
- `query`：搜索条件，页面上直接 `v-model="store.query.keyword"`
- `fetchList()`：按当前条件查一页
- `saveLab(form)`：有 `id` 就改，没有就新增；会自动剥掉表单里的空 `id`
- `fetchAllLabs()`：给下拉框用的"一次拿全部"

## 第 2 章 做一个页面，通用就这五步

后面每个页面都按这套流程，不用每次重新想。

### 2.1 什么叫"一个页面包"

一个页面 = **一个 `.vue` 文件**，加上可能用到的几个文件（比如登录页还要改路由和顶栏）。做完一个页面就叫完成一个"包"，一个包对应**一次 git 提交**。

### 2.2 五步法

1. **看目标**：这个页面做完，用户能干什么
2. **拿文件**：文档里列了要新建/替换哪几个文件
3. **抄代码**：按 0.6 的四步复制粘贴
4. **自己点一遍**：按"验收清单"一条条试
5. **提交**：`git add` + `git commit`

> 没验收完不要提交。提交了再回头改，很容易把别的页面弄坏。

### 2.3 页面长什么样（统一规矩）

所有页面长得差不多，照这个来，不用自己设计：

| 部位   | 用什么                                          | 说明                           |
| ------ | ----------------------------------------------- | ------------------------------ |
| 最外层 | `<el-card shadow="never">`                      | 一张白卡片装整页               |
| 顶部   | `<PageHeader title="xx管理" desc="一句话说明">` | 右边可以放"新增"按钮           |
| 搜索区 | `<SearchBar @search @reset>`                    | 里面放几个 `el-form-item`      |
| 表格   | `<el-table border stripe v-loading>`            | 没数据时显示 `el-empty`        |
| 分页   | `<el-pagination>` 放在 `<div class="pager">` 里 | 每页 10/20/50 条               |
| 状态   | `<el-tag :type="字典[status].tag">`             | 颜色统一从 `dict.js` 取        |
| 删除   | 先 `ElMessageBox.confirm` 再删                  | 不能点一下就没了               |
| 成功   | `ElMessage.success('xx成功')`                   | 绿色提示                       |
| 失败   | **不要自己弹**                                  | 拦截器已经弹过了，再弹会出两条 |

2. 表格有数据，不是一片空白
3. 搜索、重置、翻页都点一遍
4. 新增/编辑/删除（如果有）各做一次

### 3.3 新建 `src/stores/auth.js`

**作用**：登录成功后把 token 和用户信息存起来，刷新页面还能记住。

```js
import { defineStore } from "pinia";
import { ref, computed } from "vue";
import { login as loginApi } from "@/api/auth";

/** 容错读取本地用户信息：手动改坏 localStorage 也不至于白屏 */
function readUser() {
  try {
    return JSON.parse(localStorage.getItem("lab_user") || "null");
  } catch {
    return null;
  }
}

export const useAuthStore = defineStore("auth", () => {
  // 从 localStorage 恢复，刷新页面不掉登录
  const token = ref(localStorage.getItem("lab_token") || "");
  const user = ref(readUser());

  const isLogin = computed(() => !!token.value);
  const name = computed(() => (user.value ? user.value.name : "未登录"));

  /** 登录成功后同时写 store 和 localStorage */
  async function login(form) {
    const data = await loginApi(form);
    token.value = data.token;
    user.value = data.user;
    localStorage.setItem("lab_token", data.token);
    localStorage.setItem("lab_user", JSON.stringify(data.user));
    return data;
  }

  /** 退出：清空所有痕迹 */
  function logout() {
    token.value = "";
    user.value = null;
    localStorage.removeItem("lab_token");
    localStorage.removeItem("lab_user");
  }

  return { token, user, isLogin, name, login, logout };
});
```

**解释**：

- `token` / `user`：登录凭证和用户信息
- `localStorage.getItem(...)`：刷新后从浏览器缓存恢复，所以不会一刷新就退出
- `login(form)`：调接口，成功后写缓存
- `logout()`：清空所有登录痕迹

```js
import { createRouter, createWebHistory } from "vue-router";

const routes = [
  { path: "/", redirect: "/manager/home" },
  {
    path: "/login",
    name: "Login",
    component: () => import("@/views/Login.vue"),

    redirect: "/manager/home",
    children: [
      {
        path: "home",
        name: "Home",
        component: () => import("@/views/Home.vue"),
        meta: { title: "系统首页" },
      },
      {
        path: "lab",
        name: "Lab",
        component: () => import("@/views/Lab.vue"),
        meta: { title: "实验室管理" },
      },
      {
        path: "user",
        name: "User",
        component: () => import("@/views/User.vue"),
        meta: { title: "用户管理" },
      },
      {
        path: "equ",
        name: "Equ",
        component: () => import("@/views/Equ.vue"),
        meta: { title: "设备管理" },
      },
      {
        path: "data",
        name: "Data",
        component: () => import("@/views/Data.vue"),
        meta: { title: "数据统计" },
      },
      {
        path: "booking",
        name: "Booking",
        component: () => import("@/views/Booking.vue"),
        meta: { title: "预约管理" },
      },
    ],
  },
  {
    path: "/:pathMatch(.*)*",
    name: "NotFound",
    component: () => import("@/views/NotFound.vue"),
    meta: { public: true },
  },
];

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes,
});

// 全局前置守卫：没登录一律赶去登录页
router.beforeEach((to) => {
  const token = localStorage.getItem("lab_token");
  if (to.meta.public) {
    // 已登录还去登录页，直接进首页
    if (to.path === "/login" && token) return "/manager/home";
    return true;
  }
  if (!token) return { path: "/login", query: { redirect: to.fullPath } };
  return true;
});

// 动态改浏览器标题
router.afterEach((to) => {
  document.title = to.meta.title
    ? to.meta.title + " - 实验室预约系统"
    : "实验室预约系统";
});

export default router;
```

**解释**：

- `routes` 数组：每一条就是一个网址
- `meta: { public: true }`：这个页面不用登录也能看（登录页、404）
- `beforeEach`：每次跳页前都执行。没 token 就赶去 `/login`，并把原网址记在 `redirect` 里
- `/:pathMatch(.*)*`：通配，必须放**最后一条**，否则会把别的路由也吃掉

```js
import { defineStore } from "pinia";
import { ref } from "vue";
import {
  getReservationList,
  createReservation,
  changeReservationStatus,
  deleteReservation,
} from "@/api/reservation";

export const useReservationStore = defineStore("reservation", () => {
  const list = ref([]);
  const total = ref(0);
  const loading = ref(false);
  const query = ref({ status: "", date: "", labId: "", page: 1, size: 10 });

  async function fetchList(extra = {}) {
    loading.value = true;
    try {
      const data = await getReservationList({ ...query.value, ...extra });
      list.value = data.list;
      total.value = data.total;
    } finally {
      loading.value = false;
    }
  }

  /** 提交后自动刷新列表 */
  async function submit(form) {
    const record = await createReservation(form);
    await fetchList();
    return record;
  }

  async function changeStatus(id, status) {
    await changeReservationStatus(id, status);
    await fetchList();
  }

  async function remove(id) {
    await deleteReservation(id);
    await fetchList();
  }

  return {
    list,
    total,
    loading,
    query,
    fetchList,
    submit,
    changeStatus,
    remove,
  };
});
```

**解释**：和实验室 store 一个套路，`query` 放筛选条件，`submit` 提交后自动刷新列表。

### 8.1 做完能干嘛

只读页面：按实验室筛、按设备名/型号搜、翻页、状态标签、空数据提示。

### 8.2 页面长什么样

```text
白卡片
├── 标题："设备管理"
├── 搜索区：实验室下拉（数据用 labStore.fetchAllLabs()）+ 关键字输入框
├── 表格：序号 | 设备名称 | 型号 | 数量 | 状态 | 所属实验室 | 购置日期
└── 分页
```

### 8.3 数据怎么拿

这个页面**不用 store**，页面里自己写：

```text
query = { keyword: '', labId: '', page: 1, size: 10 }
load(): 调 getDeviceList({ ...query })，把 list / total 存起来
查询：page 回 1 再 load
重置：清空 keyword、labId，page 回 1，再 load
```

### 8.4 接口契约

**`GET /api/devices`**

| 参数            | 意思           |
| --------------- | -------------- |
| `keyword`       | 搜设备名或型号 |
| `labId`         | 只看某个实验室 |
| `page` / `size` | 分页           |

返回：

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "labId": 1,
        "labName": "计算机基础实验室",
        "name": "台式机",
        "model": "Dell OptiPlex 7010",
        "count": 60,
        "status": "normal",
        "purchaseDate": "2023-09-01"
      }
    ],
    "total": 12,
    "page": 1,
    "size": 10
  }
}
```

> `labName` 是 mock 自动补的，表格直接用，不用自己再查实验室名。

### 8.5 状态字典

| ---------- | ------ | ---- |
| `normal`   | 正常   | 绿色 |
| `repair`   | 维修中 | 橙色 |

## 第 11 章 出错了怎么办（急救手册）

### 11.1 按症状查

| 你看到的现象                                                | 最可能的原因                       | 怎么修                                                        |
| ----------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------- |
| 页面一片白                                                  | 某个 `.vue` 文件没保存/粘坏了      | 看终端红字指出的文件，重新粘                                  |
| 终端红字 `Failed to fetch dynamically imported module`      | 同上                               | 同上                                                          |
| 页面打开了但没数据，Console 没有 `[API]` 日志               | `request.js` 没挂 `adapter`        | 检查第 1.7 节代码                                             |
| 提示"接口不存在"                                            | 路径写成 `/api/labs`               | 改成 `/labs`                                                  |
| `__labMock is not defined`                                  | 不是 dev 环境，或代码没粘全        | 确认 `npm run dev` 在跑，检查 `mock/index.js`                 |
| 刷新后数据回到 8 条                                         | 浏览器清过缓存 / 无痕模式 / 换端口 | 正常，重新生成                                                |
| 改了 mock 但数据没变                                        | localStorage 里存着旧数据          | 点右上角"重置演示数据"                                        |
| 登录后刷新又回登录页                                        | 缓存 key 不一致                    | 守卫和 store 都用 `lab_token`                                 |
| 访问 `/login` 被弹回首页                                    | 已登录状态                         | 正常，先退出                                                  |
| 404 页不生效                                                | 通配路由没放最后                   | 把 `/:pathMatch(.*)*` 移到最后                                |
| 图表空白                                                    | 容器高度 0 / 用 `v-if` 藏了        | 传 `height`，改用 `v-show`                                    |
| 图表变形                                                    | 隐藏时宽度 0                       | 别删 `ChartBox` 里的 `ResizeObserver`                         |
| 分页点了没反应                                              | 事件没带括号                       | `@current-change="store.fetchList()"`                         |
| `getActivePinia() was called but there was no active Pinia` | pinia 没装或顺序错                 | `app.use(createPinia())` 放 router 前面                       |
| `Port 5173 is in use`                                       | 旧终端没关                         | 关旧窗口，或按提示换端口                                      |
| `npm install` 很慢/失败                                     | 网络                               | `npm config set registry https://registry.npmmirror.com` 再装 |
| 文件名旁边有小圆点                                          | 没保存                             | `Ctrl + S`                                                    |
| 两个人都改了同一个文件                                      | 冲突                               | 公共文件以 main 为准，找对应负责人                            |

### 11.2 怎么问人（别只说"报错了"）

按这个格式发群里，别人一眼就能帮：

```text
我在做：[第几章/哪个页面]
做了什么：[刚改了哪个文件]
现象：[完整红字，或截图]
已经试过：[刷新/重启/重置数据]
```

### 12.1 考点对照（答辩自查）

| 考点      | 在哪                                                      |
| --------- | --------------------------------------------------------- |

3. ECharts 按需引入，打包体积小
4. 纯前端数据层：axios adapter + localStorage，无后端、刷新不丢、打包后照样跑
