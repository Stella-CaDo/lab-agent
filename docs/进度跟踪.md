## 一、这个项目是什么

**纯前端 Vue 3 实验室预约系统**，没有后端、没有数据库：

- 数据全存浏览器 `localStorage`（key `lab_db_v1`），首次进页面自动灌种子数据
- 网络层用 **axios 自定义 adapter**（`mockAdapter`）在浏览器里就地处理 `/api/*`，Network 面板为空是**预期现象**，不是 bug
- 仓库里只有 `frontend/`，没有 server
- 目标形态：管理员/教师/学生三种角色，管理实验室、设备、用户，走完"提交预约 → 审核 → 统计"的闭环

技术栈：Vue 3.5 · Vite 8 · vue-router 5 · Pinia 4 · Element Plus 2.14 · ECharts 6.1 · axios 1.21
